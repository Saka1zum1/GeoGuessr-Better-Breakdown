# GeoGuessr — Meilleur bilan

Après chaque guess, sur la **carte des résultats** : **le bon endroit**, **votre pin** et **la Street View sur place**, sans quitter GeoGuessr.

Compatible **Classique**, **Défi du jour**, **Duels** et **Duels en équipe** (fin de manche et écran final).

## Fonctions principales

- **Aperçu sur les pins** — Survolez votre guess ou le pin vert : vignette Street View + distance à la couverture la plus proche.
- **Street View intégrée** — Clic sur un pin → panneau à côté de la carte.
- **Focus par manche** — En fin de partie classique, cliquez une manche dans la liste pour zoomer sur ce guess et la réponse.
- **Calque de couverture** — Le bleu Street View pour revoir où vous auriez pu vous balader.
- **Trajet sur la carte** — En vous déplaçant en SV, votre chemin se trace sur la carte de guess.
- **Anciennes prises** — Menu déroulant si plusieurs dates d’imagerie existent.
- **Outils SV** — Capture, lien, ouverture Google Maps, sauts avant/arrière, mode photo (sans interface).
- **Côté duels** — Panneau des manches, carte redimensionnable, mêmes boutons sur le breakdown duel.
- **Enregistrer sur Map-Making** — Option : sauver le spot sur [map-making.app](https://map-making.app) (clé API à la première utilisation).

## Carte et calques

Sur la carte résultat : bascule plan / satellite / relief et boutons d’overlay ajoutés par le script.

## Map-Making (optionnel)

1. Ouvrez la SV depuis un pin.
2. **Enregistrer** (icône envoi).
3. Collez votre clé API la première fois — [map-making.app/keys](https://map-making.app/keys).

## Astuces joueurs

- Fin de manche → survolez les pins avant la SV plein écran.
- Pin vert = lieu réel ; le vôtre = guess validé.
- Résumé duel → liste sur la carte pour changer de manche.
- Mode photo → bouton appareil dans la SV, **Échap** pour quitter.
