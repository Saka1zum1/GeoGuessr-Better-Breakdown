# GeoGuessr ベター・ブレイクダウン

ラウンド後の**結果マップ**で、**正解地点**・**自分のピン**・**現地のストリートビュー**をその場で見比べられます。Google マップを別タブで開く必要はありません。

**クラシック**、**デイリーチャレンジ**、**デュエル**、**チームデュエル**のラウンド結果・総合リザルト画面で動作します。

## できること

- **ピンプレビュー** — 自分のピンや正解ピンにカーソルを合わせると、SV サムネと最寄りのカバーまでの距離が出ます。
- **ページ内ストリートビュー** — ピンをクリックで、マップ横に SV パネルが開きます。
- **ラウンド単位の確認** — クラシック終了画面ではリストのラウンドを押すと、その回の推測と正解にマップが寄ります。
- **カバー表示** — 青い SV レイヤーで、街がどこまで歩けるかを振り返り。
- **移動ルート** — SV 内を移動すると、推測マップ上に通った道が線で残ります。
- **過去の撮影** — 同地点に複数時期があるとき、下部メニューで時期を切り替え。
- **SV ツール** — スクショ、リンクコピー、Google マップで開く、前後ジャンプ、フォトモード（UI 非表示のきれいな撮影）。
- **デュエル向け** — ラウンドパネル、マップのリサイズ、デュエル breakdown 上の同じ SV 操作。
- **Map-Making へ保存** — 任意：[map-making.app](https://map-making.app) に地点保存（初回のみ API キーが必要）。

## マップ周り

結果マップ上で道路／衛星／地形の切り替えや、脚本が追加したオーバーレイボタンが使えます。

## Map-Making（任意）

1. ピンから SV を開く。
2. **保存**（アップロードアイコン）をクリック。
3. 初回は API キーを入力 — [map-making.app/keys](https://map-making.app/keys) で発行。

## よく使うコツ

- ラウンド終了後、フル SV の前にピンへホバーして確認。
- 緑ピン＝正解、あなたのピン＝ロックした推測。
- デュエル summary → マップ上のリストでラウンド切り替え。
- フォトモード → SV のカメラボタン、**Esc** で終了。
